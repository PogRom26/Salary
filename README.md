# Salary

Система автоматического расчета заработной платы сотрудников B2B-направления с автоматической генерацией PDF и DOCX отчетов.

---

# Возможности

Программа автоматически:

* определяет последний расчетный период;
* считывает данные из Excel-файлов;
* рассчитывает бонус от дохода;
* рассчитывает KPI ZIC;
* рассчитывает KPI Лукойл;
* рассчитывает Другие KPI с учетом весов;
* рассчитывает ответственность за дебиторскую задолженность;
* рассчитывает показатель "Цикл сделки";
* анализирует коммуникации сотрудников;
* рассчитывает оклад по табелю учета рабочего времени;
* рассчитывает итоговую заработную плату;
* формирует индивидуальные отчеты в PDF;
* формирует индивидуальные отчеты в DOCX.

# Алгоритм расчета

## 1. Доход

Используются показатели:

* Сумма продаж
* Доход текущий
* Рентабельность текущая

Бонус:

```
Доход текущий × PROFIT_BONUS_PERCENT
```

Значение процента задается в config.py.

---

## 2. KPI ZIC

Для каждого KPI, содержащего слово ZIC:

```
Бонус = Выполнение (%) × Базовый бонус
```

Базовый бонус:

```
40 000 руб.
```

---

## 3. KPI Лукойл

Используется показатель "Факт" (кг).

Размер бонусирования:

| Продажи, кг | Ставка    |
| ----------- | --------- |
| 0–499       | 0 руб/кг  |
| 500–1999    | 5 руб/кг  |
| 2000–4999   | 8 руб/кг  |
| 5000+       | 10 руб/кг |

Пример:

```
2500 кг × 8 руб = 20 000 руб
```

---

## 4. Другие KPI

Используются KPI:

* Полярная звезда
* VegaOil
* GSK

Вес KPI:

| KPI             | Вес   |
| --------------- | ----- |
| Полярная звезда | 22.5% |
| VegaOil         | 50%   |
| GSK             | 27.5% |

Расчет:

```
Итог KPI =
Выполнение KPI × Вес KPI
```

Пример:

```
Полярная звезда:
150% × 22.5% = 33.75%
```

Все KPI суммируются.

---

### Ограничение

Используется правило:

```
если сумма KPI > 120%
то принимается 120%

если сумма KPI < 10%
то принимается 0%

иначе используется фактическое значение
```

Эквивалент Excel:

```
=ЕСЛИ(СУММ()>1,2;1,2;ЕСЛИ(СУММ()<0,1;0;СУММ()))
```

Бонус:

```
30000 × Итоговый KPI
```

---

## 5. Дебиторская задолженность

Ответственность сотрудника:

```
1% от суммы ПДЗ
```

Значение вычитается из премии.

---

## 6. Цикл сделки

### План

Используются сделки:

```
Отгрузка и доставка
```

Для каждой сделки:

```
Дата последнего изменения
-
Дата первичного контакта
```

Получается количество дней.

Среднее значение является планом.

---

### Факт

Используются стадии:

* Первичный контакт
* Выявление потребности
* Коммерческое предложение
* Опытно-производственные испытания

Для каждой сделки:

```
Дата расчета
-
Дата первичного контакта
```

Дата расчета:

последний день расчетного месяца.

---

### Бонус

Базовый бонус:

```
20 000 руб.
```

Формула:

```
Цикл план
────────── × 20 000
Цикл факт
```

Чем быстрее проходит цикл сделки, тем выше бонус.

---

## 7. Коммуникации за месяц

Анализируются:

* Визит к клиенту
* Звонок
* Отправить данные
* Подписание документов

Для каждой коммуникации выводятся:

* Общее количество
* Успешные
* Неудачные

Информация носит справочный характер.

На размер премии не влияет.

---

## 8. Табель учета рабочего времени

Сотрудник ищется по фамилии и инициалам.

Пример:

```
Аверкиева Т С
```

Используется показатель:

```
Количество отработанных часов
```

Стоимость часа задается в config.py.

Пример:

```
322.59 руб.
```

Расчет:

```
Оклад =
Часы × Стоимость часа
```

# Возможные ошибки

## Файл поврежден

Сообщение:

```
File is not a zip file
```

или

```
Unsupported format
```

Причина:

Файл Excel был поврежден при копировании.

Решение:

Открыть файл в Excel и сохранить заново.
